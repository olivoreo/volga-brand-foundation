# VOLGA Brand Foundation

Единая фирменная основа для цифровых продуктов МАУ «Волга»: **цвета и типографика**, без библиотеки компонентов.

**Версия:** `2.0.0` · **Дата:** 2026-11-23

## Файлы

- [`BRAND.md`](BRAND.md) — нормативное описание фирменных цветов, сочетаний и типографики; читать агентам в первую очередь.
- [`tokens.css`](tokens.css) — переменные цветов и адаптивной типографической шкалы; **без стилизации HTML-элементов и классов компонентов**.
- [`gallery.html`](gallery.html) — самостоятельный визуальный справочник с иллюстративными примерами. CSS внутри галереи служит лишь её отображению.
- [`CHANGELOG.md`](CHANGELOG.md) — история редакций.

## Использование в проектах

1. Зафиксировать конкретный релиз, например **`v2.0.0`**.
2. Подключить значения из `tokens.css` при сборке проекта; шрифты Unbounded Bold и Involve Regular/Medium/Bold подключать отдельно по лицензии.
3. Указать агенту файл `BRAND.md` и применяемую версию. **Не импортировать стили галереи**.
4. Обновлять бренд-версию в каждом продукте после проверки. Не ссылаться на нестабильную ветку `main` для production.

## Версионирование

Применяется `MAJOR.MINOR.PATCH`:

- **PATCH** — исправления описаний, опечатки, исправления без изменения внешнего API токенов.
- **MINOR** — новые совместимые токены/разрешённые роли или дополнительные примеры.
- **MAJOR** — переименование, удаление токенов или смена их семантики и базовых договорённостей.

По сравнению с исходной `v1.4` в версии `v2.0.0` убраны CSS-классы компонентов — **несовместимое изменение**, поэтому повышена major-версия. Репозиторий начинается с текущей редакции; старые файлы `v1.4` остаются в архиве обсуждения, а не создаются как исторические Git-теги задним числом.

Рекомендуемый путь: новый отдельный GitHub-репозиторий `volga-brand-foundation`, коммиты в `main`, согласованный `git tag v2.0.0` и GitHub Release. Для зависимых интерфейсов фиксировать номер используемого релиза в документации/файле конфигурации. Когда появятся несколько сборочных JavaScript-проектов, рассмотреть публикацию пакета в GitHub Packages/npm — на первом этапе это необязательно.

## Короткая задача агенту

> Используй `BRAND.md` версии `v2.0.0` как единую основу цветов и типографики МАУ «Волга». При разработке бери значения из `tokens.css`. Не переноси цветовые/шрифтовые решения из референсов и не импортируй CSS галереи; вёрстку и компоненты создавай под требования конкретного продукта. При необходимости изменения основы предложи правку в репозиторий бренда, не меняй токены локально.
