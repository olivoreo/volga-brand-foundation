# МАУ «Волга» — Brand Foundation

**Версия:** 2.2.0
**Дата:** 23.11.2026  
**Область действия:** единая палитра и типографика цифровых интерфейсов МАУ «Волга».  
**Источник истины:** этот документ. `tokens.css` содержит те же значения в машинно-читаемом виде; `gallery.html` показывает примеры сочетаний.

Значения палитры, шрифтовых семейств, начертаний и типографической шкалы — нормативные. Примеры сочетаний демонстрируют применение цветов, а не готовые компоненты.

## 1. Цветовая система

### Базовые роли

| Токен | HEX | Назначение |
|---|---|---|
| `--volga-bg` | `#FCFDFF` | Основной почти белый, холодно-нейтральный фон |
| `--volga-surface` | `#FFFFFF` | Светлые поверхности и области содержимого |
| `--volga-heading` | `#0B1634` | Основные заголовки, тёмные фоновые области |
| `--volga-text` | `#1E2537` | Основной текст |
| `--volga-text-secondary` | `#3D4C67` | Вторичный текст, метаданные |
| `--volga-primary` | `#2954C7` | Фирменный акцент, ссылки, основные действия |
| `--volga-primary-soft` | `#E3EFFF` | Мягкие акцентные поверхности |
| `--volga-divider` | `#E1E8F2` | Малоконтрастные декоративные разделения |
| `--volga-control-border` | `#60728C` | Цвет различимых функциональных границ |
| `--volga-text-on-dark-muted` | `#B2BFD3` | Вторичный текст на navy `#0B1634` |

Для светлого текста на тёмном фоне и фирменном синем использовать `--volga-on-dark` и `--volga-on-primary` (оба `#FFFFFF`).

`#E1E8F2` слишком светлый для границы, которая **должна** быть видна для распознавания элемента. `#60728C` предназначен для функциональных границ, не для обычного текста. Светло-синие оттенки исходного логотипа `#81ABF5`, `#BCD4F6` не используются как текст на белом фоне. Фирменный знак сохраняет собственные оригинальные цвета: он не перекрашивается под цвета элементов интерфейса.

### Цвета действий и ссылок

Доступны следующие цветовые сочетания; выбирается **цветовое состояние**, а не готовый способ отрисовки компонента.

| Сценарий | Обычное сочетание | При наведении — основной вариант | Допустимая альтернатива |
|---|---|---|---|
| Основное синее действие | фон `#2954C7`, текст `#FFFFFF` | фон `#FFFFFF`, текст `#2954C7` (инверсия) | фон `#2348AD`, текст `#FFFFFF` |
| Светлое вторичное действие | фон `#FFFFFF`, текст `#2954C7` | фон `#2954C7`, текст `#FFFFFF` (инверсия) | фон `#E3EFFF`, текст `#2954C7` (мягкий вариант) |
| Светлое действие на navy | фон `#FFFFFF`, текст `#0B1634` | фон `#0B1634`, текст `#FFFFFF` | — |

Для текстовых ссылок цвет задан отдельно и не связан с альтернативным затемнением кнопок:

| Контекст | Обычная ссылка | Hover | Visited |
|---|---|---|---|
| Светлая поверхность | `#2954C7` | `#1D355F` | `#1D355F` |
| Navy `#0B1634` | `#FFFFFF` | `#B2BFD3` | `#B2BFD3` |
| Фирменный синий `#2954C7` | `#FFFFFF` | `#E3EFFF` | `#E3EFFF` |

`visited` — состояние ранее посещённого URL, а не кратковременное нажатие. Отдельного фирменного цвета `pressed` нет. Технически `:visited` применяется к настоящим ссылкам и ограничивается браузерами в целях приватности; цвет visited должен оставаться различимым и контрастным. Доступность интерактивных состояний оценивается на реализованной странице.

**Дополнительные цветовые токены:**

| Токен | HEX | Роль |
|---|---|---|
| `--volga-primary-hover-alt` | `#2348AD` | Альтернативный hover основного синего действия |
| `--volga-link-hover` / `--volga-link-visited` | `#1D355F` | Hover и visited ссылок на светлом фоне |
| `--volga-link-on-dark-hover` | `#B2BFD3` | Hover и visited ссылок на navy |
| `--volga-link-on-blue-hover` | `#E3EFFF` | Hover и visited ссылок на фирменном синем |

### Системные состояния

Использовать по назначению — не как декоративную палитру лендинга.

| Роль | Передний план | Светлая поверхность |
|---|---|---|
| Успех | `#167447` (`--volga-success`) | `#EAF7EF` (`--volga-success-bg`) |
| Ошибка | `#B42318` (`--volga-error`) | `#FFF0EE` (`--volga-error-bg`) |
| Предупреждение | `#8A4C00` (`--volga-warning`) | `#FFF6E9` (`--volga-warning-bg`) |

Системный статус должен быть понятен не только по цвету.

### Тёмная тема (добавлена в v2.1.0)

Тёмный режим — **опциональная** тема для цифровых продуктов; светлая тема остаётся базовой. Включение выполняется приложением через атрибут `data-theme="dark"` на корневом элементе или обёртке. Без атрибута действуют прежние светлые значения. Темы содержат одинаковые имена токенов: **переключается роль цвета, а не типографика**.

| Токен | Light | Dark | Назначение в dark |
|---|---|---|---|
| `--volga-bg` | `#FCFDFF` | `#0B1634` | Основной фон |
| `--volga-surface` | `#FFFFFF` | `#1E2537` | Поверхности |
| `--volga-heading` | `#0B1634` | `#FFFFFF` | Заголовки |
| `--volga-text` | `#1E2537` | `#F2F5FC` | Текст |
| `--volga-text-secondary` | `#3D4C67` | `#B2BFD3` | Вторичный текст |
| `--volga-primary` | `#2954C7` | `#81ABF5` | Акцент/ссылки |
| `--volga-primary-soft` | `#E3EFFF` | `#1D355F` | Приглушённый акцентный фон |
| `--volga-divider` | `#E1E8F2` | `#3D4C67` | Декоративное разделение |
| `--volga-control-border` | `#60728C` | `#8CA0BC` | Различимые границы |
| `--volga-on-primary` | `#FFFFFF` | `#0B1634` | Текст на акценте |
| `--volga-on-dark` | `#FFFFFF` | `#FFFFFF` | Светлый текст на тёмном |
| `--volga-text-on-dark-muted` | `#B2BFD3` | `#B2BFD3` | Приглушённый светлый текст |

В тёмной теме `--volga-primary-hover-alt`, `--volga-link-hover`, `--volga-link-visited` и `--volga-link-on-dark-hover` используют `#BCD4F6`; `--volga-link-on-blue-hover` — `#1D355F` (контрастный тёмный hover на светло-синем акценте). Для светлого текста на синем в тёмной теме используйте `--volga-on-primary` (тёмный navy), а не неизменный белый.

| Системный статус | Текст Dark | Фон Dark |
|---|---|---|
| Успех | `#83DDAE` | `#153D31` |
| Ошибка | `#FFABA5` | `#4A242A` |
| Предупреждение | `#FFD18A` | `#49351F` |

**Цветовые пары dark:** акцентное действие — `#81ABF5` / `#0B1634`; hover-инверсия — `#1E2537` / `#81ABF5`, альтернативное осветление — `#BCD4F6` / `#0B1634`. Вторичное действие — поверхность `#1E2537` / текст `#81ABF5`; мягкий hover — `#1D355F` / `#81ABF5`. Ссылка на тёмном фоне: обычная `#81ABF5`, hover и visited — `#BCD4F6`. При использовании отдельной насыщенно-синей поверхности проверить контраст пары, а не переносить белый текст автоматически.

Исходные фирменные цвета логотипа **не заменяются** ночными оттенками. Цветовая система не предписывает переключатель темы, геометрию элементов, анимации или компоненты. `prefers-color-scheme` можно использовать в самом приложении для выбора атрибута, но этот файл ничего не переключает автоматически.

## 2. Типографика

### Семейства и начертания

Для заголовков предусмотрены **две типографические роли**. Семантический уровень HTML и визуальное оформление разделены: один и тот же HTML-тег может использовать разные шрифтовые роли в зависимости от контекста.

| Роль | Шрифт | Начертание | Регистр | Применение |
|---|---|---|---|---|
| **H1–H2, акцентные заголовки (по умолчанию)** | **Unbounded** | **Bold 700** | **UPPERCASE** | Первый экран, ведущие заголовки страниц и значимые разделы |
| **H3–H4, обычные заголовки (по умолчанию)** | **Involve** | **Bold 700** | Естественный | Разделы, карточки, списки, диалоги, таблицы, информационные блоки |
| **H1–H2 в информационно насыщенных интерфейсах (допустимо)** | **Involve** | **Bold 700** | Естественный | Панели управления, мини-приложения и административные интерфейсы |
| Основной текст, описание, длинный текст | **Involve** | **Regular 400** | Естественный | Абзацы и основной контент |
| Вводные абзацы, навигация, подписи | **Involve** | **Medium 500** | Естественный | Навигация, вводная информация и подписи |
| Выделение и текст основного действия | **Involve** | **Bold 700** | Естественный | Важные акценты и действия |
| Вторичный текст, дата, метаданные | **Involve** | **Regular 400** | Естественный | Дополнительные сведения |

**Правило по умолчанию:** H1–H2 — Unbounded Bold CAPS, H3–H4 — Involve Bold без принудительного верхнего регистра. Unbounded применяется точечно как фирменный акцент, а не для каждого заголовка. Не нужно менять семантический HTML-тег ради выбора шрифта. Для H5–H6, если они необходимы, использовать Involve Bold по аналогии с интерфейсными заголовками.

Новые типографические алиасы: `--volga-font-display` — Unbounded, `--volga-font-ui-heading` — Involve, `--volga-ui-heading-case` — `none`. Существующие `--volga-font-headings` (Unbounded), `--volga-font-text` (Involve), `--volga-heading-case` (uppercase) сохраняются для совместимости. Последний задаёт регистр **акцентных** заголовков, а не всех HTML-заголовков.

Не подменять фирменные семейства шрифтами из референсов и не имитировать недостающий вес искусственным утолщением (`font-synthesis: none`). Шрифты подключаются в каждом проекте с учётом лицензий; файлы шрифтов в комплект не включены.

### Размеры и интерлиньяж

Размеры — CSS px при стандартном базовом размере 16 px; в `tokens.css` приведены в `rem`.

| Роль | ≥ 1200 px | 768–1199 px | ≤ 767 px | Высота строки |
|---|---:|---:|---:|---:|
| H1 (обычно Unbounded) | **56** | 44 | **32** | 1.15 |
| H2 (обычно Unbounded) | **40** | 34 | **26** | 1.20 |
| H3 (Involve Bold) | **24** | 22 | **20** | 1.26 |
| H4 (Involve Bold) | **20** | 19 | **18** | 1.40 |
| Lead, Involve Medium | **22** | 20 | **19** | 1.50 |
| Body, Involve Regular | **18** | 17 | **17** | 1.60 |
| Reading, Involve Regular | **17** | 16 | **16** | 1.65 |
| Secondary / metadata | **15** | 15 | **15** | 1.50 |
| Текст действия | **16** | 16 | **16** | 1.45 |
| Значение поля | **16** | 16 | **16** | 1.50 |
| Подпись / навигация | **16** | 16 | **16** | 1.40 |

На экранах шириной **≤359 px**: H1 — **28 px**, H2 — **24 px**. Остальные размеры не меняются. Для акцентного заголовка H1 предусмотрен `letter-spacing: -0.01em`; для H2–H4 — `0`. Основной текст имеет обычный межбуквенный интервал. Крупность и структура текста должны сохраняться при адаптации; семантический уровень заголовка не определяется внешним видом карточки.

Для коротких комбинаций заголовка и описания выбирать явно различающиеся уровни (например, Involve Bold H3 + Reading). Это **пример типографической иерархии**, не обязательный шаблон карточки.

## 3. Читаемость и контроль качества

- Контраст обычного текста: **не менее 4.5:1**, крупного текста: **не менее 3:1**, значимых графических элементов управления: **не менее 3:1** относительно смежных цветов (WCAG 2.2 AA).
- Подбирать контрастные сочетания цветов для состояний, не передавать смысл только изменением цвета.
- Сохранять различимость клавиатурного фокуса; выбранный способ отображения проверять в конкретном интерфейсе.
- Длинные текстовые абзацы читать удобнее при длине строки ориентировочно **55–75 знаков**; для адаптивных экранов подбирать ширину без обрезания содержимого.
- Проверять увеличение текста, переносы кириллических заголовков и мобильную ширину 320 CSS px.

**Примеры контрастных пар:** `#1E2537` на `#FCFDFF`, `#3D4C67` на `#FCFDFF`, `#FFFFFF` на `#2954C7`, `#2954C7` на `#FFFFFF`, `#2954C7` на `#E3EFFF`, `#B2BFD3` на `#0B1634`.

## 4. Использование агентами и обновления

1. При проектировании использовать цветовые и типографические **роли**, а не подбирать новые HEX или семейства под конкретный референс. По умолчанию H1–H2 — Unbounded Bold, H3–H4 — Involve Bold; исключения для плотных интерфейсов описаны в разделе типографики.
2. Для вариантов интерактивных состояний выбирать одну из утверждённых **цветовых пар**; новые цветовые значения обсуждать перед внедрением.
3. В проекте реализовывать компоненты самостоятельно на основе референсов и задач, не копировать стили визуального справочника как библиотеку компонентов.
4. Считать этот Markdown нормативным; `tokens.css` — отражением его значений; `gallery.html` — иллюстрацией, а не шаблоном сайта.
5. При изменении бренда обновлять соответствующие токены, документ, визуальные примеры и версию выпуска согласованно.
